## Context
The reference App renders Concept map and Lab walkthrough via Infographic.tsx with separate artwork, fit/zoom/pan/download and readable summaries. Its optional narrated concept tour uses Claude-specific recorded MP3s. Our workspace has mounted Learn/Run/Source panels, typed lesson content, coloured code and account-scoped progress.

## Goals / Non-Goals
Goals: both requested tabs throughout the course; accurate Mastra-specific visual content; scalable downloadable diagrams with accessible text; concrete six-phase walkthroughs; mobile/keyboard/theme support and preserved ongoing exercises.
Non-goals: porting Claude artwork/audio, generating narrated recordings, automatic execution or grading, a separate workbook submission system, persistent walkthrough completion or a progress-contract migration. Walkthrough position remains during tab changes but resets on reload/lesson/account change.

## Decisions
- Append `infographic` and `walkthrough` after Learn/Run/Source. Preserve old order/URLs/default and mounted panels. Use a responsive wrapping tablist for five long labels; existing generic tabs continue to support arrow/Home/End navigation. Add additive course-map URLs.
- Build browser-safe teaching models from each LabDefinition plus a curated four-stage concept flow for every lab number, including orientation. Title, summary, objectives, inputs, procedure, prerequisites, expected output, checks and challenge come from registered content. Avoid introducing new Mastra methods or external claims; the existing installed 1.79.0 runtime/compatibility evidence remains authoritative.
- Match the owner's six supplied Mastra style references: white canvas, pale blue/mint/violet rounded panels, blue/green iconography, numbered flows, a small illustrated robot and dark terminal/code windows. Render original code-native SVG posters with distinct concept and walkthrough compositions, evidence and boundary callouts. This keeps text sharp, editable and self-contained without model calls or large image bundles. Short visual excerpts link to complete HTML text summaries; exports also offer full Markdown text. Reuse safe formatted prose and JSON highlighting.
- Include short syntax-coloured teaching excerpts copied from declared non-solution lesson reference files, with source path/line and an explicit surrounding-setup-omitted label. Select and verify these excerpts from the existing typed Source API rather than inventing samples or bundling server reference/configuration code into the frontend. The attached slides guide visual style; their Lesson 3 numbering does not remap this portal's Lab 03 or override its pinned versions.
- Shared viewer owns fit/zoom (25–200%), bounded internal scrolling, pointer panning, native fullscreen dialog with Escape/focus return, SVG download and PNG export through canvas. Exports serialize only static trusted React SVG text; no HTML, external images/fonts or secrets. Report export failures accessibly and keep SVG/text alternatives.
- Six phases: goal, preparation, baseline, evidence, changed scenario, explanation. Use real example inputs and lesson-specific checks/challenge. Explicit actions open existing sections without starting runs or altering drafts. Selecting a phase highlights its diagram node and retains the current phase during tab switches; study navigation is not execution evidence.

## Risks / Trade-offs
Long content requires short artwork excerpts plus full text summaries; downloads must remain readable at native size. Zoomed posters intentionally scroll inside a focusable viewport, never the whole page. Diagrams teach a process but cannot assert it executed. Existing Learn/Run/Source behavior and account progress must stay unchanged. Native SVG/canvas export may be denied; show an actionable error and preserve the alternate formats.
