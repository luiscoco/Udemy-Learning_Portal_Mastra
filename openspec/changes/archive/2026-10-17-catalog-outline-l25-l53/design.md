# Design

## Decisions

- **Titles are taken verbatim** from the owner's pasted outline. The original source is kept outside the repo in `.data/prompts/L24-L53.md`.
- **Module titles become confirmed** only for modules whose labs were named in the outline (06–11). Module 11 contains L51–L55, so it is confirmed although L54–L55 are still pending.
- **No lab changes availability.** `AVAILABLE_LAB_NUMBERS` is untouched; locked labs keep rendering the locked state with the new title.
