# Third-party software

The root MIT license covers original project code and documentation. Dependencies retain their own licenses and notices; the project license does not replace them. The source ZIP excludes installed dependency code. `npm ci` installs the exact dependency graph in `package-lock.json`, including dependency license/notice files.

Major components include Mastra core and the MCP SDK (Apache-2.0), React, Express, Vite, TypeScript, Zod and ZIP tooling under their respective package licenses. Review each installed package's LICENSE/NOTICE and package metadata when redistributing dependencies or compiled applications. Do not remove third-party notices. Separately distributed Udemy recordings, branding and instructor-owned media are not included in the source archive or relicensed by this notice.
